# naia-android-string-compat

기존 NAIA Android 앱용 업데이트와 확장 소스입니다. APK를 다시 설치할 필요가 없습니다.

## 갤탭에서 설치

1. NAIA **Settings → Extension → GitHub에서 설치**에 아래 주소를 붙여 넣으세요.

   ```text
   https://github.com/FechoKurrera/naia-android-string-compat/tree/android-tools-repair
   ```

2. **NAIA Android 업데이트 1.1**을 신뢰하고 활성화한 뒤 **내장 0.2.9 수정본 적용 → 수정한 확장 다시 불러오기**를 누르고 화면을 새로고침하세요. 예전 복구·업데이트 도구는 꺼도 됩니다.
3. **히스토리 → 사진·폴더 → 사진 불러오기**에서 **안드로이드 폴더 선택**으로 원하는 하위 폴더를 지정하세요. 지원되지 않는다는 안내가 나오면 **기기에서 사진 선택**으로 사진을 복사할 수 있습니다.
